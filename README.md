# OrbitOS Releases

Distribution artifacts and signed manifests for OrbitOS. The product development repository and its Git history remain private.

Current uploads are development-channel builds for controlled Intel Mac and Apple Silicon Mac testing. They are not a stable public product release. Use a matching OrbitOS Desktop / OrbitOS Node pair supplied for the same test build.

Runtime downloads are public and require no GitHub token or account. OrbitOS verifies its pinned signing key, platform, channel, exact byte length and SHA-256 before installation. Account authentication and entitlements remain separate from artifact hosting.

Published runtime tags and assets are versioned and are not replaced. The signed development catalog is updated only after its referenced asset is uploaded and verified. No signing key, user data, credentials or private development Git history is stored here.
